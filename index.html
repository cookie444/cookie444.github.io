Software

Daisy Pedal HIL Test Rig

A hardware-in-the-loop test harness that verifies audio hardware against measurable spec thresholds instead of manual listening. It generates known signal stimuli, captures the response, and asserts pass/fail on metrics like latency, THD, frequency response, and repeat decay — every tolerance centralized in one config file. The same suite runs against a simulated reference model in CI on every push and against real hardware on a self-hosted runner, emitting JUnit XML and waveform reports for the checks panel and offline triage. Fault injection proves the harness catches regressions, not just green builds.

PSARC Pipeline

Queue-driven download manager for CustomsForge Rocksmith CDLC. A FastAPI service turns search and enqueue requests into Postgres-backed jobs; async workers claim them off a Redis queue, authenticate to CustomsForge, resolve each song’s real host link, and stream the file to disk. Rate limiting, retries, and host-specific downloaders for Google Drive, Dropbox, and MediaFire handled explicitly.
